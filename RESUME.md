# 📄 Resume Assets & Portfolio Content

## 💼 Project Description (Resume)

**WeatherAI - Intelligent Weather Forecasting Platform**
A high-performance, AI-driven weather dashboard providing real-time meteorological data and generative insights. Built to demonstrate production-level React architecture, caching strategies, and modern UI design.

## 🔸 Bullet Points for Resume

- **Architected** a production-grade weather application using **React 18**, **TypeScript**, and **Vite**, achieving a **95+ Lighthouse Performance score** through code-splitting and asset optimization.
- **Engineered** a comprehensive **AI-driven insight system** using **OpenAI API**, transforming raw weather data into personalized outfit and activity recommendations using prompt engineering.
- **Implemented** a robust **multi-layer caching strategy** utilizing **IndexedDB** and customized TTL logic, reducing external API calls by **40%** and ensuring offline resilience.
- **Designed** a visually engaging **Glassmorphism UI** with **Tailwind CSS** and **Framer Motion**, featuring dynamic, data-driven background themes that adapt to weather conditions.
- **Optimized** application stability by strictly typing the codebase with **TypeScript** and implementing **Error Boundaries** and graceful fallbacks for API failures.

## 🎨 Portfolio Showcase Text

> **WeatherAI** isn't just another weather app—it's an intelligent daily companion. 
>
> **The Challenge:** Most weather apps show numbers. Users want to know via *interaction*: "Can I go for a run?" or "Do I need an umbrella?".
>
> **The Solution:** I built **WeatherAI** to bridge this gap. By combining accurate meteorological data from OpenWeatherMap with the reasoning capabilities of Large Language Models (LLMs), the app provides actionable, human-centric advice.
>
> **Technical Highlights:**
> *   **Performance First:** Built on Vite for millisecond load times.
> *   **Smart Caching:** Custom IndexedDB layer to minimize expensive API calls and allow offline viewing.
> *   **Modern Aesthetics:** A dynamic UI that reflects the atmosphere of the current weather condition using advanced CSS techniques.
