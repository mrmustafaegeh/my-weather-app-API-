# Weather App

A modern weather forecast app using **React** and **OpenWeather API**.  
Get real-time weather updates for any city worldwide.

## 🚀 Features
- 🌍 Search weather by city
- ☀️ Current temperature, humidity, and wind speed
- 📱 Responsive and user-friendly UI
- ⚡ Fast API integration with async handling

## 🛠️ Tech Stack
- React.js
- OpenWeather API
- Tailwind CSS
